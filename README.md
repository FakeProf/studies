## GitHub Pages

Quelle ist der Branch `main`, Ordner `/ (root)`. Die Datei `index.html` im Wurzelverzeichnis leitet auf `lernstand/` weiter, damit auch `https://fakeprof.github.io/studies/` funktioniert. `.nojekyll` schaltet den Jekyll-Build ab — die Seiten werden unverändert ausgeliefert.

Kommt später ein zweites Projekt dazu, wird aus der Weiterleitung eine Übersichtsseite.
